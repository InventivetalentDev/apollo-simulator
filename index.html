Click a command to key it into the DSKY, or type on your keyboard: digits, V verb, N noun, Enter, C clear, P pro, K key rel, R reset.Tap a command to key it into the DSKY. Tap a lamp or an underlined word to see what it means.

    When the PROG lamp lights, key VERB 05 NOUN 09 to show the alarm codes, then hover overtap one on the DSKY for its meaning, or look it up here.

      No alarm code matches.

      • The DSKY was the crew's keyboard and display. Every lamp and digit here is set by the original 1969 software, through the same I/O channels the real hardware used.
      • The listing is the actual Apollo 11 source. Your browser assembles it into the 36 banks of core rope, and an emulated Block II computer runs it at 85,333 memory cycles a second.
      • The source comes from chrislgarry/Apollo-11 on GitHub. Click any line number in the listing, or the file and line under “Running”, to open the same line there.
      • In the LM, the computer is wired to a simulated spacecraft: the IMU and its angle counters, the 16 RCS jets, the hand controller, the descent engine, the landing radar and the LM's orbit around the Moon. The autopilot and the landing guidance are the original code.
      • This simulator is free software under the GNU GPL, version 2 or later. Its source code is on GitHub. Parts of the assembler and the emulator are translated from yaYUL and yaAGC by Ron Burkey, from the Virtual AGC project.
